# Character

The `Character` tab contains information about the follower, such as their health / stamina / magicka, level, and currently [equipped weapons]({{ '/inventory/' | relative_url }}#weapons).

![Character]({{ "/assets/img/panel/character.png" | relative_url }}){: .screenshot loading="lazy"}

## Breakdowns

Hovering over values reveals detailed breakdowns.

![Character magic hover]({{ "/assets/img/panel/character_magic_hover.png" | relative_url }}){: .screenshot loading="lazy"}

Breakdowns use game formulas as best as they're understood. They're reconciled against true [actor values](https://en.uesp.net/wiki/Skyrim_Mod:Actor_Value_Indices), with unknown sources (e.g. scripted effects) grouped under `Other`.

![Character breakdown other]({{ "/assets/img/panel/character_breakdown_other.png" | relative_url }}){: .screenshot loading="lazy"}
