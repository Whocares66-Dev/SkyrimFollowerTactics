; ============================================================
;  FollowerTactics - configure the SELECTED follower
;
;  Click the follower in the console, then:  bat ftmake
;  Repeat for the second follower.
;
;  Marcurio  000B9986   Destruction Mage, a real magicka pool
;  Jenassa   000E1BA9   Ranger
;
;  WHY CLICKING, AND NOT A REFID IN THE FILE
;  From a batch file, exactly two things reach a specific actor:
;      player.<command>                        works
;      <command>, on a PRIOR selection         works
;  Both of these were tried and neither works:
;      prid <refid>                            no
;      <refid>.<command>                       no
;  Batch lines are queued and run in no reliable order, so
;  anything that depends on an earlier line in the same file is
;  broken. A selection made BEFORE the batch is stable state,
;  which is why the second form is safe and prid is not.
;
;  POTIONS, weak then strong. Two tiers on purpose: the engine
;  drinks the STRONGEST carried, so watching which count falls
;  proves it chose correctly rather than merely drinking.
;    0003EADD / 0003EADE   Minor Healing / Healing
;    0003EAE0 / 0003EAE1   Minor Magicka / Magicka
;    0003EAE5 / 00039BE8   Minor Stamina / Stamina
;  All six read off the running game. Stamina breaks the
;  adjacent-pair pattern the other two follow.
;
;  Check with a SEPARATE `bat ftstatus` -- a check inside this
;  file could run before the thing it checks.
; ============================================================
