; ============================================================
;  FollowerTactics - configure the SELECTED follower
;
;  Click the follower in the console, then:  bat ftmake
;  Repeat for the second follower.
;
;  Marcurio  000B9986   Destruction Mage, a real magicka pool
;  Jenassa   000E1BA9   Ranger
;
;  THEN TALK TO HER AND CHOOSE "Follow me."
;  This file no longer sets setplayerteammate / CurrentFollowerFaction.
;  Those make a TEAMMATE, which the potion rules are happy with, but
;  cast rules run through the DialogueFollower quest's alias and its
;  combat-override package list, and only "Follow me" (SetFollower)
;  fills that alias. The relationship rank set below is what makes the
;  line appear. FollowerTactics.log says "in the DialogueFollower
;  alias: yes/NO" the first time a cast rule fires, so a wrong recruit
;  is diagnosed rather than guessed.
;
;  WHY CLICKING, AND NOT A REFID IN THE FILE
;  From a batch file, exactly two things reach a specific actor:
;      player.<command>                        works
;      <command>, on a PRIOR selection         works
;  Both of these were tried and neither works:
;      prid <refid>                            no
;      <refid>.<command>                       no
;  Batch lines are queued and run in no reliable order, so
;  anything that depends on an earlier line in the same file is
;  broken. A selection made BEFORE the batch is stable state,
;  which is why the second form is safe and prid is not.
;
;  POTIONS, weak then strong. Two tiers on purpose: the engine
;  drinks the STRONGEST carried, so watching which count falls
;  proves it chose correctly rather than merely drinking.
;    0003EADD / 0003EADE   Minor Healing / Healing
;    0003EAE0 / 0003EAE1   Minor Magicka / Magicka
;    0003EAE5 / 00039BE8   Minor Stamina / Stamina
;  All six read off the running game. Stamina breaks the
;  adjacent-pair pattern the other two follow.
;
;  SPELLS. Two, because they test different things.
;
;  Fast Healing 0002F3B8 is deliberately NOT granted here.
;  Marcurio already carries a healing spell, and adding a second
;  one makes the spell menu ambiguous -- pick the wrong entry and
;  the cast rule names a spell the package does not hold, which
;  reads as a broken rule rather than a mismatched pick.
;
;  It matters which exact form he knows: FollowerTactics.esp
;  authors its UseMagic packages to cast 0002F3B8 specifically,
;  so if his native heal is a DIFFERENT form the package has to
;  be re-authored to match it. `bat ftstatus` reports hasspell
;  for that exact id.
;
;  Flames 00012FCD -- Novice Destruction, CONCENTRATION: the
;  stream lasts as long as the hand is held. This is the sustained
;  cast case, and it is here to be watched, not because it works:
;  the record's CastTime inputs are 0.5..1 s and the release fires
;  on the spell-fire event, which for a concentration spell marks
;  the START of the stream. docs/MAGIC.md "Open" has the plan.
;
;  Costs are listed at skill 0 and fall with the school's skill.
;  Check the follower can actually afford one with `bat ftstatus`
;  before concluding the rule engine is at fault -- a caster who
;  cannot pay looks exactly like a rule that never fired.
;
;  Check with a SEPARATE `bat ftstatus` -- a check inside this
;  file could run before the thing it checks.
; ============================================================

setrelationshiprank player 4

additem 0003EADD 10
additem 0003EADE 5
additem 0003EAE0 10
additem 0003EAE1 5
additem 0003EAE5 10
additem 00039BE8 5
