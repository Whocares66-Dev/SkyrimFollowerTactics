;  her persistent reference and failed exactly that way on a
;  level-1 save.
;
;  placeatme with her BASE id (000A2C8E) sidesteps all of it:
;  it works at any point in any save, in any cell, regardless of
;  quest state. The copy is disposable, which is what you want in
;  a test anyway.
;
;  NEXT STEP, and it cannot be batched: click her in the console
;  to select her, then run  bat ftmake
;  (Console commands act on the selected reference, and there is
;  no console command to select the thing placeatme just made.)
; ============================================================

player.tgm

; 000A2C8E = Lydia's BaseID. Any humanoid NPC base works here.
