; ============================================================
;  FollowerTactics - configure the SELECTED follower
;
;  Click the follower in the console, then:  bat ftmake
;  Repeat for the second follower.
;
;  Marcurio  000B9986   Destruction Mage, a real magicka pool
;  Jenassa   000E1BA9   Ranger
;
;  THEN TALK TO HER AND CHOOSE "Follow me."
;  This file no longer sets setplayerteammate / CurrentFollowerFaction.
;  Those make a TEAMMATE, which the potion rules are happy with, but
;  cast rules run through the DialogueFollower quest's alias and its
;  combat-override package list, and only "Follow me" (SetFollower)
;  fills that alias. The relationship rank set below is what makes the
;  line appear. FollowerTactics.log says "in the DialogueFollower
;  alias: yes/NO" the first time a cast rule fires, so a wrong recruit
;  is diagnosed rather than guessed.
;
;  WHY CLICKING, AND NOT A REFID IN THE FILE
;  From a batch file, exactly two things reach a specific actor:
;      player.<command>                        works
;      <command>, on a PRIOR selection         works
;  Both of these were tried and neither works:
;      prid <refid>                            no
;      <refid>.<command>                       no
;  Batch lines are queued and run in no reliable order, so
;  anything that depends on an earlier line in the same file is
;  broken. A selection made BEFORE the batch is stable state,
;  which is why the second form is safe and prid is not.
;
;  POTIONS, weak then strong. Two tiers on purpose: the engine
;  drinks the STRONGEST carried, so watching which count falls
;  proves it chose correctly rather than merely drinking.
;    0003EADD / 0003EADE   Minor Healing / Healing
;    0003EAE0 / 0003EAE1   Minor Magicka / Magicka
;    0003EAE5 / 00039BE8   Minor Stamina / Stamina
;  All six read off the running game. Stamina breaks the
;  adjacent-pair pattern the other two follow.
;
;  SPELLS. Two, because they test different things.
;
;  Fast Healing 0002F3B8 is deliberately NOT granted here.
;  Marcurio already carries a healing spell, and adding a second
;  one makes the spell menu ambiguous -- pick the wrong entry and
;  the cast rule names a spell the package does not hold, which
;  reads as a broken rule rather than a mismatched pick.
;
;  It matters which exact form he knows: a cast rule names a
;  form, and two spells can share a display name (Marcurio's own
;  heal is 0007231C, the vanilla one 0002F3B8). `bat ftstatus`
;  reports hasspell for that exact id.
;
;  Flames 00012FCD -- Novice Destruction, CONCENTRATION: the
;  stream lasts as long as the hand is held. This is the sustained
;  cast case, and it is here to be watched, not because it works:
;  the record's CastTime inputs are 0.5..1 s and the release fires
;  on the spell-fire event, which for a concentration spell marks
;  the START of the stream. docs/MAGIC.md "Open" has the plan.
;
;  Costs are listed at skill 0 and fall with the school's skill.
;  Check the follower can actually afford one with `bat ftstatus`
;  before concluding the rule engine is at fault -- a caster who
;  cannot pay looks exactly like a rule that never fired.
;
;  POWERS, for the Use power action (docs/ACTIONS.md 7). Marcurio
;  already has one from his race -- Voice of the Emperor 000E40CA,
;  an Imperial's -- which is why the Magic tab's Powers chip is not
;  empty before this runs. Added here:
;    00088821   Embrace of Shadows  vampire power, Self: invisible
;               and night eye for 180 s. Chosen because its effect
;               is visible at a glance and lasts long enough to be
;               read off the Effects tab. Performed through a Shout
;               package wrapping the power: UseMagic never fired one.
;
;  A SHOUT, for the Shout action: the same shout slots a power goes
;  through, with the shout itself in the package's input.
;    00013E07   Unrelenting Force  Fus Ro Dah, all three words. An NPC
;               shouts the highest filled word (measured 2026-09-05),
;               so this is the full three-word shout and its long
;               animation -- the case a power deliberately avoids. It
;               is aimed, so the rule goes under Enemy or Target:
;               IF target: any THEN target: Shout -> Unrelenting Force.
;               addshout puts it on the base record's shout list, where
;               the Greybeards' are, and the Magic tab's Shouts chip.
;
;  CONJURATION, for the Summon and Corpse conditions to come.
;    000204C3   Conjure Flame Atronach  Location delivery, the spell
;               itself (0A26EC is its tome). One summon at a time is the
;               engine's rule for an NPC too; "Summon: Active" reads the
;               commanded-actor list on the follower.
;    00065BD7   Reanimate Corpse  Aimed at a corpse of level 13 or less
;               for 60 s (the effect's magnitude is the level cap). Kill a
;               bandit with bat ftman first: the bear leaves no corpse the
;               spell will take -- well, it does, but a bear at level 12
;               is exactly the Serana-raises-a-rat case the Corpse
;               condition is meant to rank away from.
;
;  FOOD and INGREDIENTS, for the Consume menu's other two lists.
;  Both go through the same equip call as a potion; whether an
;  NPC gets the effect is unverified (the player eating an
;  ingredient learns its first effect; an NPC has nothing to learn).
;    00064B33   Goat Cheese Wheel   food, restore health
;    0004B0BA   Wheat               ingredient, restore health first
;    000727DE   Blue Butterfly Wing ingredient, damage stamina first --
;               here so the list has one that would be a MISTAKE to
;               eat, as a real bag does.
;
;  GEAR, for the Inventory tab's hands and pins. Iron, so it is
;  plainly WORSE than what Marcurio wears and so nothing goes on
;  by itself: the equip-best logic only swaps upward. Putting it
;  on is the panel's job, and whether it stays on across a fight
;  is what the pin watchdog is being watched for.
;    00012E49   Iron Armor    body, heavy -- displaces the robes
;    00012EB6   Iron Shield   left hand -- contests a spell there
;    0001397E   Iron Sword    one-handed -- either hand
;    0003B562   Long Bow      two-handed -- the pinned-bow case, and
;    0001397D   Iron Arrow    the arrows it needs to be listed at all
;
;  Check with a SEPARATE `bat ftstatus` -- a check inside this
;  file could run before the thing it checks.
